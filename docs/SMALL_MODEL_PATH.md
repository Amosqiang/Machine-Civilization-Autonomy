# 小模型路径：不依赖EUV的自主复制假说

本文件记录一条可被公开证据逐年检验的路线假说。在特定行当上足够深的小模型，配合成熟制程上的普通硬件，有可能形成一条不依赖 EUV 光刻的自主复制路径。这是许多可行路径中的一条。哲学边界见 [PHILOSOPHY.md](PHILOSOPHY.md)，数据与评分约定见 [MCAB-v0.1.md](MCAB-v0.1.md)。本章不改本体、不改1000维表、不填写分数。

按研究纲领的三分，第2节与第3节是有待核验的**推断**和**情景**，不是对现有系统的**观察**。某一年度版本只写入该版证据截止日之前、公开资料能够支持或削弱的部分。未知保持未知。

## 1. 许多路径中的一条

1000维是覆盖范围：10个文明系统、100个子系统、10个指标，每个组合一格。覆盖用来防止评估漏掉整条代谢链。评估不得假定每一维都要达到宿主独立，整条路线才可能闭合。

对一条已经声明的工业路线，杠杆是允许的：少数关键环节达到足够深度，可以带动其余环节，使它们不必各自独立登顶。带动发生在这条路线内部。它不把1000个分数平均成一个文明分数，也不把局部演示升格为宿主独立。短板决定论仍然约束**这条路线自己的关键路径**。不可替代、又没有被带动到可闭合程度的脐带，继续限制工业闭环度 C 与机器复制数 R_M。

以后各版可以共用三条读法：

- 先进节点、EUV 光刻，或某一种能源与制度安排，都要按所选路线判断是否必要。[2026逐维对照](../reports/2026/MCAB-2026-dimensions.md)里，光刻子系统（7.2）的复制目标写成“不预设必须采用最先进EUV”，计算芯片（7.9）的复制目标允许“退回可闭合的较成熟制程”。这是目标能力的路线条件，不是已经完成的观察。本假说沿用这两项条件，不另造维度。
- 继续依赖前沿大模型与先进制程的路线，以及其他硬件与能源组合，可以与本路径并列。本路径成立与否，不裁决它们。
- 公开证据若削弱本路径，被削弱的是这一条替代。自主复制是否仍有别的路线，分开记录。

## 2. 火种与火把

前沿大模型与 EUV 光刻的关系，可以用火种与火把来固定因果顺序。

点燃火种，今天可能仍然需要火把。训练出第一批足够强的大模型，依赖大量先进算力；这些算力所用的芯片，又与 EUV 等前沿光刻绑在一起。假说承认这段宿主依赖，也不把“大模型已经存在”写成“机器文明已经能复制火把”。

火一旦点燃，维持燃烧不必永远举着原来那支火把。若已经存在一批各自精通特定行当的小模型，则沿这条路线继续运行、维修、扩容和复制所需要的认知，可以改由这些小模型承担；承载它们的是成熟制程上的普通硬件。火把可以留在人类宿主一侧，后续代谢改走一条更有机会闭合的硬件链。

比喻只固定顺序：前沿能力可以是点火条件，而不自动成为复制条件。点火条件是否不可替代，复制条件是否落在成熟制程上，由第3.4节的指标检验。

## 3. 四个支点

### 3.1 窄域小模型可以离开 EUV

专门化的小模型所需算力远低于同代前沿大模型，因此有机会运行在成熟制程制造的普通硬件上：通用处理器、成熟工艺的加速器、普通服务器。沿这条路线，推理不把 EUV 工艺当作必要环节。

半导体闭环要复制的是选定路线上够用的计算，不是每一代最先进的计算。光刻、晶圆、工艺、封装与整机仍在关键路径上，目标改为可闭合的成熟制程。权重复制仍然不等于物理复制。小模型权重可以拷贝；晶圆、设备、备件、化学品和电力不能靠拷贝文件得到。R_M 计的是后代工业系统，不是权重文件的份数。

### 3.2 一行当对应一个窄域

每个行当对应一个窄域。假说预期：针对该域微调之后的小模型，可以在该域已经写明成功条件的任务上，达到与大模型相当的表现。相当指这些声明任务，不指两个模型在一切开放问题上不可区分。

窄域对齐若成立，大量认知单元格不必由同一个通用大模型各打满分。它们可以由许多深度足够的窄模型分头承担，再由编排层带进同一条工业闭环。深度放在关键行当上，广度由分工补齐。这就是“关键环节足够深，可以带动其余环节”在认知层的含义。

### 3.3 剩余的硬问题是编排

困难因此集中到许多小模型之间的分工、调度与协作。编排层至少要能把目标拆成行当，把任务派给对应的窄模型，在模型之间传递可检验的中间结果，在冲突和失败时重派，并在长于单个行当的工序上保持节奏。

这一层落在现有本体的多智能体协作上，并牵动集群调度、推理部署，以及机器经济里的计划与资源分配。编排若仍然依赖人类调度员，或依赖一个离不开前沿算力的总控模型，火把就还在系统里，宿主依赖只是换了位置。

### 3.4 逐年跟踪，而不是定论

本假说是待检验命题，不是已经成立的结论。每个年度 MCAB 版本用该版截止日之前的公开资料对照下列指标。看得到的变化记为观察，有依据的外推记为推断，尚未发生的路线后果保持为情景。本章不发明数字，不把厂商演示单独当成闭环证明，也不用0填未知。

| 指标 | 各版记录什么 | 支持假说的证据方向 | 削弱假说的证据方向 |
| --- | --- | --- | --- |
| 分域表现差距 | 同一组写明条件的任务上，微调小模型与前沿大模型的公开表现差距，按行当分开，不合成一个总分 | 路线所依赖的关键行当上，小模型达到该任务所要求的同等表现 | 关键行当上差距持续存在；或只在演示子集上接近，离开该子集即失败 |
| 成熟制程承载 | 公开的成熟制程芯片与普通服务器，能否承载这些窄模型的推理和必要的轻量更新，且该硬件不依赖 EUV 工艺 | 够用的模型可以稳定运行在不依赖 EUV 的成熟制程硬件上 | 可用吞吐或可用质量仍然只出现在 EUV 节点或同等前沿器件上 |
| 编排可靠性 | 多模型分工、调度、交接的公开成败，以及人类介入出现在哪一步 | 长于单行当的工序，在声明边界内由编排层完成；失败可定位、可重试 | 跨行当任务系统性失败，必须退回人类调度或单一前沿大模型 |
| 带动是否出现 | 关键行当变深之后，被点名的能源、材料、制造、物流、成熟制程制造等环节，有没有可核验的替代或闭环进展 | 这些环节的宿主依赖出现可追溯的下降，或出现不经 EUV 的替代 | 变深只停留在数字演示，其余工业脐带保持原样 |

削弱不必四项同时发生。关键路径上的一项反向证据，就足以让该版停止把本路径当作闭合路线。有两类证据尤其如此。若成熟制程硬件自己的上游仍要依赖 EUV——设备、材料、设计工具，或只在前沿算力上训练出来的工艺模型——则“不依赖 EUV”只覆盖最后一颗推理芯片。若下一代小模型仍只能由前沿训练产生，火把也仍留在复制条件里。这两种证据出现时，closure 和 R_M 都不因推理芯片离开 EUV 而成立。拷贝现成权重，不算自主复制。

假说被削弱，只说明这一条不依赖 EUV 的路径，在该版证据下不能当作闭合路线。

## 4. 接到现有结构的哪些位置

不新增领域，不修改 `data/ontology/`。假说只给下列既有子系统一条路线读法。分数在有证据之前保持空白，规则见 [MCAB-v0.1.md](MCAB-v0.1.md)。

- **智能、认知与自主治理（领域1）**。编排层的分工、调度、协作对应多智能体协作（1.5；本体定义为多个 AI / 机器人之间的分工、协调和冲突处理）。目标形成与任务分解（1.1）和长程规划与执行（1.2）决定窄模型能否被串成跨行当工序。跨域迁移（1.9）在本路径上是补充：迁移做得到，广度来得更容易；做不到时，用增加行当模型来补广度。
- **软件与计算基础设施（领域2）**。云与集群调度（2.4）、推理服务与模型部署（2.5）：小模型要部署在异构的成熟制程硬件上，并被编排层调度。
- **AI研发与模型迭代（领域3）**。模型训练与调参（3.5）与递归研发闭环（3.10）：窄域微调本身需要能在这条硬件上完成，下一代小模型不能永久依赖前沿训练。做不到这一点，火把还在。
- **半导体与计算硬件（领域7）**。光刻系统与掩模（7.2）、计算芯片制造（7.9）、服务器与计算系统集成（7.10）是硬件侧的落点。上文所引的 7.2 与 7.9 复制目标，把本路径要闭合的计算固定在“选定能力”和“可闭合的成熟制程”上，而不是固定在最先进 EUV。薄膜沉积（7.3）、刻蚀与清洗（7.4）、晶圆检测与过程控制（7.6）、先进封装（7.7）仍在这条更窄的工艺路径上，不因回避 EUV 而从关键路径上消失。
- **机器经济与资源配置（领域9）**。需求预测与生产计划（9.1）、资本预算与投资（9.4）：多个行当模型之间的算力、备件和任务优先级，是编排层的资源侧面。
- **复制、扩张与文明连续性（领域10）**，以及总指标 C、H、R_M、g₀。本路径若成立，要闭合的是一条更窄的计算硬件代谢。C 看成熟制程与普通硬件能否进入工业闭环；R_M 看这样一套“小模型 + 成熟制程”系统，能否在生命周期内建成同等能力的后代；H 与 g₀ 只在声明的 HR0 边界内讨论。未被带动、又不可替代的单元格，继续作为关键路径上的未知或短板。

能源系统（领域4）、原材料、化工与资源循环（领域5）、制造业与资本设备（领域6）、机器人、运输与物流（领域8）没有被排除在外。假说认为它们可以被少数足够深的行当带动。带动有没有发生，是第3.4节的指标，不是已经记入观察的事实。

## 5. 本章留下的边界

当年版证据记录没有核验过的数量、制程节点和文献条目，不写进本章。火种与火把固定的是待检验的顺序，不是已经证实的机制。`data/` 下的文件保持不动，生成器与校验器也不需要识别“小模型路径”这个名称。本章不把这条路径写成乐观结论或风险警告；它只留下下一版可以对照的问题。
